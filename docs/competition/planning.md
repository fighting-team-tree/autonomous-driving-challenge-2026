# 트랙 1 — 모션 Planning

인지된 주행 환경에서 충돌을 피하고, 도로를 벗어나지 않으며, 목적지 방향으로 진행하는
**미래 궤적을 생성하는** 모델을 만듭니다.

담당: ETRI 노진홍 선임 (jinhong.p.noh@etri.re.kr)

## 과제 정의

- 모델이 **운전자 역할을 대신**합니다. 센서에서 추출된 인지 데이터를 받아
  **10Hz로 계속** 행동(조향·가감속)을 출력합니다
- 목표 세 가지: **안전할 것 / 원하는 방향으로 잘 이동할 것 / 부드럽게 움직일 것**
- 평가 방식은 **non-reactive closed-loop**: 시뮬레이터가 장면을 만들면 주변 객체·신호등은
  기록된 실환경 데이터가 그대로 재생되고, 자차만 모델이 제어합니다
- 테스트 시 **미래 정보는 가려집니다.** 과거만 볼 수 있습니다

## 데이터셋 {#dataset}

Planning과 [궤적예측](prediction.md)은 **완전히 동일한 데이터셋**을 씁니다.

| 데이터셋 | TFRecord 수 | 용량 | Scene 수 |
|---|---|---|---|
| 2024.12 서울 | 953 | 133G | 84,000 |
| 2024.12 제주 | 370 | 49G | 29,000 |
| 2025.03 서울 | 1,618 | 233G | 140,000 |
| 2025.03 제주 | 134 | 13G | 7,000 |
| **계** | **3,075** | **428G** | **260,000** |

- 3,075개 주행 로그(10Hz)에서 **9.1초 단위 Scene 약 260,000개**를 추출
- 구조는 **Waymo Open Dataset 형식**을 따름 ([참고](https://github.com/waymo-research/waymo-open-dataset))
- 학습용은 2,460 TFRecords (208,000 Scene)
- TFRecord로 제공되며 **pkl 변환 코드가 함께 제공**됨
- 수집: 라이드플럭스. **하남·화성·제주** 3개 지역, 약 885시간.
  지역별로 평균 속도·주변 객체 수·신호등 수가 크게 다름
- 원본은 30초 기록이며, non-reactive 방식의 한계(자차가 다른 행동을 하면 주변 차량과
  어긋남)를 줄이기 위해 **9초 단위로 잘라서** 평가

Scene에 담긴 것: 주변 동적 객체(차량·보행자·자전거)의 상태, 도로 배치, 교통 신호 변화.
목적지는 마지막 유효 위치를 잡아 사용합니다.

## 평가

### 1차 (Cut-off)

전체 테스트 시나리오 처리 시간이 기준을 초과하면 실시간성 부족으로 **탈락**.

- 기준: **PDM 알고리즘 대비 1.5배 초과 시 탈락**
- 참고: PDM 처리시간은 시나리오당 0.028초 (RTX 4090, batch 64)

### 2차 (최종 점수)

$$
\text{ScenarioScore} = \text{no\_collision} \times \text{on\_road} \times \frac{7 \cdot \text{progress} + 3 \cdot \text{comfort}}{10}
$$

- `no_collision` (이진): 충돌 없으면 1, 발생 시 0
- `on_road` (이진): 도로 위 유지하면 1, 이탈 시 0
- `progress`: 목적지까지의 진행 정도 (0~1)
- `comfort`: jerk, acceleration, yaw rate 기반 주행 편안함 (0~1)

**충돌이나 도로 이탈이 나면 그 시나리오는 통째로 0점**입니다. 진행도를 조금 더 얻으려다
주차 차량과 부딪히면 점수가 몰수됩니다.

### 재현성 평가

상위 득점 팀에게 학습 코드를 받아 성능 재현 여부를 직접 확인합니다.

## 제출

- **WaymaxActorCore 형태**로 모델과 가중치 제출
- 평가는 **Waymax 시뮬레이터 기반 평가 스크립트**
- 리더보드 종료 후 최고점 제출물에 대해 학습 코드를 받아 재현 확인
- 의존성 추가가 필요하면 requirements를 함께 제출 가능 (설치 과정이 평가에 포함됨)

!!! danger "제출 전 반드시 확인"
    - **실행되지 않으면 즉시 0점**
    - 평가 제한 시간 초과 시 0점
    - **NaN 등 예외 발생 시 해당 배치는 점수로 처리되지 않음**

    배포된 테스트 코드로 사전 검증하고 올릴 것. 한 번에 처리할 장면 수는 미리 실험된
    수치가 제공되므로 참고할 것.

### 배포 코드에 이미 들어있는 것

- **train/val 분할 코드**
- **비활성화된 손실 항목과 지표들** — 충돌·도로 이탈 등이 이미 구현돼 있음.
  보상에 넣은 항목만 점수가 오르고, 지표로만 찍혀 있는 것은 통제되지 않음
- 새 항목을 만들려면 기존 함수 옆에 작성하면 그대로 동작
