- 리더보드는 실시간 갱신, 트랙별로 운영
- 제출물
    - **Planning**: 학습된 모델의 명세 코드 + 모델 가중치 파일
    - **궤적예측 / E2E**: 검증 파일에 대한 추론 결과 파일
- 챌린지 종료 후 수상 후보 팀에게 **코드 공개 요청** 예정
  (학습·추론 코드, pretrained weight, 학습 결과 weight, 실행 가능한 Docker 이미지)

## 평가 구조

세 트랙 모두 **2단계**입니다.

1. **1차 (Cut-off)** — 실시간성 검증. 기준 초과 시 **탈락**
2. **2차 (최종 점수)** — 정확도와 추론 속도를 결합한 종합 점수
3. **재현성 평가** — 상위 득점 팀에게 학습 코드를 받아 성능 재현 여부를 직접 확인

허용 오차에 대한 담당자 답변: *"1등이 재현성 평가를 했을 때 2등과 순위가 바뀌지 않을 정도면 합리적"*.
